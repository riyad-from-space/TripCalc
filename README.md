# TripCalc

A Flutter app for tracking trip expenses day by day, by category, with automatic per-person cost splitting and trip summaries.

## Features

- **Email/password accounts** with Firebase Auth, a verification email on sign-up, and access to the app only after the email is verified.
- **Sign-up validation**: email format check, password rules (8+ chars, upper/lower case, number, special character) and a live password-strength meter.
- **Create trips** with a name and number of people; expected duration and budget can be entered under "Advanced options".
- **Day-by-day expense entry**: each trip has a current day; enter amounts, *Save Day* to keep progress, *Complete* to close the day and move on to the next one.
- **Predefined categories**: Transportation, Food, Accommodation, Activities and Miscellaneous, each with subcategories (e.g. Food → Breakfast, Lunch, Dinner).
- **Custom categories** can be added for the day being edited.
- **Per-person split**: day and trip totals are divided evenly by the number of people on the trip.
- **Completed days view** listing each finished day's total and per-person cost, with a detailed day screen showing the category breakdown, share of the day's total and per-person amount for each category.
- **Trip completion and summary**: mark a trip complete to lock it, then view total spent, cost per person, people, number of days and a day-wise breakdown.
- **Home dashboard** with total spent across all trips, trip count, and active vs. completed trips, plus a card per trip.
- Real-time updates from Firestore, an animated splash screen and a native splash via `flutter_native_splash`.

Amounts are shown in Bangladeshi Taka (৳).

## How it works

Each trip is a single document in a top-level Firestore `trips` collection, tagged with the owner's `userId`; the home screen streams only the signed-in user's trips. A trip stores its name, number of people, optional expected duration/budget, a `status` (`running` or `completed`), the `currentDay`, a `completedDays` list and a running `totalCost`. Daily spending lives in a `dailyExpenses` map keyed `day_1`, `day_2`, …, where each entry holds an `expenses` map (category key → amount), the day's `total` and a timestamp. Category keys are stored as `"Main (Sub)"`, e.g. `"Food (Lunch)"`, or as the plain name for custom categories, and only amounts above zero are saved. Saving a day rewrites that day's entry and recalculates `totalCost` from all day totals; per-person figures are calculated on screen as total ÷ people.

## Getting started

**Prerequisites**

- Flutter SDK, stable channel, 3.24 or newer (Dart SDK `^3.5.4`, as set in `pubspec.yaml`)
- A Firebase project of your own
- [FlutterFire CLI](https://firebase.google.com/docs/flutter/setup) (`dart pub global activate flutterfire_cli`) and the Firebase CLI, logged in

**1. Set up Firebase**

In the [Firebase console](https://console.firebase.google.com/), create a project, then:

- **Authentication** → enable the **Email/Password** sign-in provider.
- **Firestore Database** → create a database. The app reads and writes a `trips` collection; rules that limit each user to their own trips look like this:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /trips/{tripId} {
      allow read, update, delete: if request.auth != null && resource.data.userId == request.auth.uid;
      allow create: if request.auth != null && request.resource.data.userId == request.auth.uid;
    }
  }
}
```

**2. Connect the app to your project**

```bash
git clone https://github.com/riyad-from-space/TripCalc.git
cd TripCalc
flutterfire configure
```

`flutterfire configure` regenerates `lib/firebase_options.dart` and writes the platform config files (`android/app/google-services.json`, and `GoogleService-Info.plist` for iOS) for your own project. `main.dart` calls `Firebase.initializeApp()` without options, so it reads those platform files at startup.

**3. Run**

```bash
flutter pub get
flutter run
```
